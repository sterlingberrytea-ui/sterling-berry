Switch to Vercel

Move Sterling Berry from Netlify to Vercel in about 10 minutes. All functions have been pre-converted.

Step 1

Create a Free Vercel Account

  1. Go to vercel.com → Sign up with GitHub (recommended) or email
  2. Free "Hobby" plan includes: unlimited sites, 100GB bandwidth, 100k function invocations/month, custom domain
Vercel's free tier is more generous than Netlify's for serverless functions.
Step 2

Upload Your Files

You have two options:

Option A — GitHub (recommended for ongoing updates):

  1. Create a new repo at github.com/new
  2. Upload all your site files — HTML, CSS, JS, the api/ folder, vercel.json, package.json
  3. In Vercel → New Project → Import Git Repository → select your repo
  4. Vercel auto-deploys on every push — no manual uploads needed going forward

Option B — Drag & Drop:

  1. In Vercel dashboard → New Project → select "Deploy from file system"
  2. Zip your entire site folder and drag it in
Make sure your folder structure is: api/ at the root (NOT inside netlify/functions/). The vercel.json must be at the root too.
Step 3

Step 4

Update Stripe Webhook URL

  1. In Stripe Dashboard → Developers → Webhooks → your endpoint
  2. Change the URL from https://your-site.netlify.app/api/stripe-webhook to https://your-site.vercel.app/api/stripe-webhook
  3. Copy the new webhook signing secret → update STRIPE_WEBHOOK_SECRET in Vercel
Step 5

Add Your Custom Domain

  1. Vercel → Project → Settings → Domains → Add sterlingberry.com
  2. Vercel shows you DNS records to add at your domain registrar (usually just 2 records)
  3. SSL certificate is automatically provisioned — usually live within 5 minutes
Step 6

What Changed (Function Syntax)

Your functions were auto-converted. Here's the difference for reference:

Netlify (old)

exports.handler = async (event) => {
  const body = JSON.parse(event.body);
  if (event.httpMethod !== 'POST')
    return { statusCode: 405,
             body: 'Not allowed' };
  return { statusCode: 200,
           body: JSON.stringify({ok:true}) };
}

Vercel (new)

export default async function handler(req, res) {
  const body = req.body; // auto-parsed
  if (req.method !== 'POST')
    return res.status(405).send('Not allowed');
  return res.status(200).json({ ok: true });
}
